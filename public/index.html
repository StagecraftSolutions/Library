    API

    Statische JSON-Dateien, bei jedem Deploy aus dem Git-Stand neu erzeugt. Kein Schlüssel nötig, CORS ist offen. Jede Antwort enthält commit und generatedAt, damit Abnehmer wissen, welchen Stand sie haben.

    Unter rackmanufaktur/ liegen dieselben Daten im Format, das Rackmanufaktur heute in seinem data/-Ordner pflegt – damit kann Rackmanufaktur seine Daten künftig direkt von hier beziehen.

    Pflege

    Daten bearbeiten

    Jeder Artikel ist eine eigene JSON-Datei unter data/articles/<bereich>/<unterkategorie>/<id>.json. Änderungen laufen über Git – mit Verlauf, Review und Pull Requests.

    1. Datei anlegen oder ändern – Editoren mit JSON-Schema-Unterstützung (z. B. VS Code) schlagen Felder vor und markieren Fehler.
    2. node scripts/build.mjs --check prüft alle Artikel.
    3. Committen und Pull Request öffnen; nach dem Merge holt der Server den Stand und baut die API neu.
    4. Im Artikel-Detail führt „In Git bearbeiten“ direkt zur Datei.
